Unit 2.1 — Colors

Brand Palette

A deliberately small palette. Two logo colors, five theme colors, and a handful of state colors the print book never needed but a UI does.

Brand Colors

Everything on this card comes straight from the brand book. Use the CSS variable, not the hex — the variable is what every page already declares.

Red Logo
#DC282E
var(--red)
Pantone 186C · CMYK 4 / 94 / 87 / 0
Primary brand red. Logo, destructive actions, alerts, required-flags.
Dark Grey
#4E4E50
var(--dark-grey)
Pantone Black 7C · CMYK 63 / 55 / 51 / 51
Logo wordmark. Secondary body text and field labels.
Light Red
#F15F5E
var(--light-red)
CMYK 0 / 78 / 58 / 0
Softer red for fills and accents where full red is too loud.
Light Blue
#4FB0E3
var(--blue)
CMYK 62 / 14 / 0 / 0
The workhorse accent: active tabs, focus rings, links, card borders.
Blue Dark
#2D2D3B
var(--dark)
CMYK 78 / 73 / 52 / 54
Primary text, dark surfaces, primary buttons, photo filter.
Grey
#B9BDCB
var(--grey)
CMYK 10 / 7 / 0 / 20
Muted text, disabled states, hairlines, empty-state copy.
Light Grey
#F3F2F2
var(--light-grey)
CMYK 1 / 1 / 1 / 2
App background. Never a text color.

State Colors (Web Only)

Not in the printed book — a screen UI needs success, warning, and hairline values the brand palette does not supply. These are the ones already in production across the tools; do not invent new ones.

Green
#2E9E5B · --green
Amber
#C98A00 · --amber
Border
#E0E2EA · --border
White
#FFFFFF · --white
Tinted backgrounds. States use a pale wash plus a saturated text color, never the saturated color as a fill: green #E7F6EE / #2E9E5B, amber #FDF6E3 / #7A5B10, red #FDECEC / #9E2A2E, blue #E9F5FC / #2E7CA6.
