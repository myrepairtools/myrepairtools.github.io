Unit 3.0 — Typography

Typography

The brand book specifies Avenir. Avenir has no web license here, so screen work substitutes Nunito for display and Nunito Sans for body — a documented, deliberate substitution, not drift.

Type Families

Brand book spec · print
Avenir
Book · Medium · Heavy · Black. Elegant, clear, readable. Use for all print, signage, vehicle wraps, and anything a designer produces in Adobe CC.
BookBody copy, long form
MediumSubheadings

Web substitution · screen
Nunito / Nunito Sans
Nunito (display) carries every heading, button, label, and number. Nunito Sans (body) carries paragraphs and field text. Both are geometric humanist sans faces — the closest freely-licensable match to Avenir’s tone.
Sans 400/600Body copy, inputs
Sans 700Field values, table cells
Nunito 800Labels, buttons, tabs
Nunito 900Headings, stat numbers
Do not mix the two systems in one artifact. A print piece is Avenir throughout; a screen is Nunito throughout. Never set a web page in a fallback serif or system stack — load the Google Fonts link.

Display

Use it for
big titles
Book reference. Big headings are Avenir Black, lower case — sentence case, not caps. Small headings are Avenir Black, capitalized. That split carries over: page titles are sentence case, section eyebrows are uppercase.
