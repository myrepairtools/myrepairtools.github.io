Unit 4.3 — Graphic Resources

Buttons

All buttons are rounded rectangles set in the display face. The brand book’s print spec is Avenir Black caps at 5px radius; the web build uses Nunito 800 sentence case at 10px — recorded below so the divergence stays intentional.

Web Buttons

What every tool page ships today. .btn is dark by default — the primary action. Secondary is the white .alt; red is reserved for destructive.

Print Buttons (Brand Book Spec)

For designed collateral, ads, and any Adobe-produced asset. Avenir Black, all caps, 5px radius. Outline variants use a 1px rule; icon-outline buttons use 0.5px.

Two specs on purpose. Print keeps the book’s 5px/caps/Avenir rule. Screen uses 10px/sentence-case/Nunito because caps-at-.78rem is unreadable in a dense tool UI. Do not “fix” one to match the other — pick by medium.
