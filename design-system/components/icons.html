Unit 4.2 — Graphic Resources

Iconography

Minimal line icons in the CPR color scheme. The web build standardizes on Lucide at 2px stroke, inheriting currentColor so an icon tints with whatever contains it. No emoji in UI chrome.

Usage

All 44 glyphs live in one map — NAV_SVG in assets/nav.js — exposed as window.CPRNavIcon(name, size). Add new glyphs there from the lucide-static package; never inline a one-off SVG in a page.
