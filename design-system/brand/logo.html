Unit 1.0 — Logo

Logo

Three approved lockups — wide, vertical, icon. The wide mark is the default and the only one that ships in this repo; nothing outside these three is an approved lockup.

Background Treatments

The same wide lockup in its three approved settings. Which one you reach for is decided by the background, never by preference.

PrimaryLight backgrounds. The default everywhere it fits.
InvertedDark backgrounds and filtered photo treatments.
MonochromeOn brand-colored fields. Keep contrast sufficient.
Over photography. Put the primary logo on a light area or the inverted logo on a dark one. If the photo is busy, apply the dark-blue filter from Unit 4.5 first — never add a shadow or a plate behind the mark.

Lockup Variants

Pick by the shape of the space, not by taste.

Wide

The primary lockup. Designed for wide displays — headers, letterheads, signage, web nav.

Vertical

Only where a vertical display is genuinely the most appropriate option — narrow columns, tall signage, portrait collateral.

Not in this repo — add the corporate file to assets/images/ before using.
Icon

Small or crowded spaces where the brand still needs to identify itself — favicons, app icons, avatars. Also for large-format use where the brand should read quietly.

Not in this repo — add the corporate file to assets/images/ before using.

Exclusion Zone

Clear space around the logo equals the width of the letters “CPR” in the lockup (the icon version uses the width of “CP”). Nothing enters this area — no text, no rules, no photo edges.

In CSS terms. Whatever container holds the mark, give it padding equal to the “CPR” width on all four sides. Practically: never let the logo sit tighter than 0.6em of its own rendered height.

Minimum Sizes

Below the readable size the mark stops being legible; below the recommended size it stops looking deliberate. Do not go under these.
